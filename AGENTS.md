# Sakura System — AutoCenter Edition

Este projeto **não usa Next.js** (era um projeto anterior chamado "Pneus Amigão" — foi
completamente substituído). A stack atual é Electron + Vite + React + TypeScript + Tailwind CSS,
com Supabase como backend.

**Antes de fazer qualquer alteração, leia `PROJETO_STATUS.md`** — ele contém o contexto completo
do projeto, decisões já tomadas, modelagem de dados, o que já foi construído/validado, dívidas
técnicas conhecidas e os próximos passos. Mantenha esse arquivo atualizado a cada funcionalidade
nova concluída.
